REST API Endpoints Specification
METHOD ENDPOINT URL DESCRIPTION PAYLOAD / OUTPUT
GET /api/restaurants Fetch all registered restaurant partners JSON Array of restaurants
GET /api/restaurants/{id}/surplus Fetch surplus food list for a specific restaurant Surplus items & statuses

GET /api/volunteers/available List available volunteers ready for delivery Available volunteer heroes

POST /api/allocations Manually re-run Decision Engine on an existing donation Feasibility & compatibility score
